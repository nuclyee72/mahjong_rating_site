# 마작 레이팅 웹사이트 (Mahjong Rating Site)

개인전 및 대회전 기록을 관리하고 통계를 볼 수 있는 독립형 마작 레이팅 웹사이트입니다.

## 커스텀 설정 안내

포크(Fork) 또는 클론(Clone) 후 본인만의 사이트로 구축하기 위해 다음 파일들을 수정해 주세요.

### 1. 사이트 이름
`app.py` 파일의 최상단(18번째 줄 근처)에 있는 `CLUB_NAME` 변수를 본인의 동아리명이나 모임 이름으로 변경하세요.
```python
CLUB_NAME = "<동아리명>"  # 이 부분을 원하는 이름으로 변경하세요
```

### 2. 아이콘 및 이미지 교체
현재 `static` 폴더에 들어있는 아이콘 파일들은 이전 설정이 남아있을 수 있습니다. 모임 성격에 맞는 아이콘(예: 마작패 이미지, 로고 등)으로 직접 덮어씌워 주셔야 합니다.
- `static/favicon.ico`: 브라우저 탭에 표시되는 기본 아이콘
- `static/icon.png`: 모바일 홈 화면 추가 등에 쓰이는 192x192 해상도 아이콘

### 3. PWA 매니페스트 수정
스마트폰에서 '홈 화면에 추가'를 할 때 표시되는 앱 이름을 변경하려면 `static/manifest.json` 파일을 수정하세요.
- `"name"` 과 `"short_name"` 항목을 원하는 이름으로 변경하시면 됩니다.

### 4. 기본 룰(Rule) 설정
`config.json` 파일에서 점수 계산 방식, 기본 점수, 우마 등을 수정할 수 있습니다.
- `"START_SCORE"`, `"RETURN_SCORE"`, `"UMA"`, `"OKA_TO_1ST"`: 점수 체계 관련
- `"RULES_PERSONAL"`, `"RULES_TOURNAMENT"`: 게임 규칙 텍스트

## 🚀 실행 방법 (How to Run)

이 프로젝트는 **Python Flask**를 기반으로 만들어졌습니다.

1. **파이썬 설치**: Python 3.8 이상의 버전이 설치되어 있어야 합니다.
2. **의존성 라이브러리 설치**: 터미널(명령 프롬프트)을 열고 프로젝트 폴더로 이동한 뒤 아래 명령어를 입력하세요.
   ```bash
   pip install -r requirements.txt
   ```
3. **서버 실행**:
   ```bash
   python app.py
   ```
4. **접속**: 브라우저를 열고 `http://localhost:5000` 으로 접속하면 웹사이트를 사용할 수 있습니다.

---

## 💾 데이터베이스 및 백업 안내

- 이 사이트는 별도의 복잡한 DB 설치 없이 가벼운 **SQLite**를 사용합니다.
- 처음 서버를 실행하면 폴더 내에 `games.db` 파일이 자동 생성되며, 모든 대국 기록과 통계가 이곳에 저장됩니다.
- 사이트를 다른 컴퓨터로 옮기거나 데이터를 백업하고 싶을 때는 이 `games.db` 파일만 복사해서 보관하시면 됩니다. (또는 웹사이트 내의 '관리자 기능' 탭에서 CSV 형식으로 내보내기/가져오기가 가능합니다.)

## ✨ 주요 기능

- **개인전 및 대회전 기록**: 4인 마작 점수를 입력하면 설정된 룰(우마, 오카)에 따라 자동으로 pt를 계산하여 저장합니다.
- **다양한 통계 제공**: 누적 pt, 평균 등수, 연대율, 토비율 등의 개인 상세 통계 및 최근 등수 추이 그래프를 제공합니다.
- **뱃지 시스템**: 특정 조건을 달성한 플레이어에게 관리자가 뱃지(칭호)를 부여하여 플레이어 상세 화면에 뽐낼 수 있습니다.
- **모바일 완벽 호환 (PWA)**: 스마트폰 웹 브라우저의 '홈 화면에 추가' 기능을 사용하면 마치 하나의 앱처럼 쾌적하게 동작합니다.
